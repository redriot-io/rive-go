[![CI](https://img.shields.io/github/actions/workflow/status/redriot-io/rive-go/ci.yml?label=CI&logo=githubactions&logoColor=white)](https://github.com/redriot-io/rive-go/actions)

Read, write, and build [Rive](https://rive.app) `.riv` files entirely in Go — no C bindings, no runtime dependency.

**[Live preview →](https://redriot-io.github.io/rive-go/preview/)**

---

## Features

- **Binary reader** — parse any `.riv` file into a typed object graph
- **Binary writer** — serialize an object graph back to spec-compliant bytes
- **Fluent builder API** — construct scenes, animations, and state machines programmatically
- **350 generated types** — full coverage of Rive runtime property definitions (shapes, paths, animations, state machines, layouts, …)
- **Text support** (Phase 2B) — embedded fonts, multi-run styled text, alignment/overflow/sizing, animated text properties
- **Image support** (Phase 3-3) — PNG/JPEG embedding via builder + FromJSON; rivtool --deep image validation
- **Audio support** (Phase 3-5) — WAV/MP3/OGG embedding via builder + FromJSON; rivtool --deep audio validation; AudioEvent(407) triggers
- **Bone support** (Phase 3-4) — RootBone/Bone hierarchy, skin binding; IK, Distance, and Transform constraints; bone rotation/translation/scale keyframe animation
- **`rivtool` CLI** — inspect, validate, font/image/audio-check `.riv` files; `--deep` verifies glyph coverage + image/audio magic bytes
- **Pure Go** — no cgo, no external runtime required

## Quickstart

```go
import (
    "github.com/redriot-io/rive-go/rive/builder"
    "os"
)

func main() {
    b := builder.New()
    ab := b.Artboard("Main", 500, 500)

    rect := ab.Rectangle(150, 175, 200, 150).
        Fill(0xFFCC3333).
        Name("rect")

    ab.Animation("fadeIn", builder.WithDuration(30), builder.WithLoop(builder.LoopLoop)).
        KeyframeFloat(rect, builder.PropOpacity, 0, 0.0, builder.Linear()).
        KeyframeFloat(rect, builder.PropOpacity, 30, 1.0, builder.Linear())

    data, err := b.Bytes()
    if err != nil {
        panic(err)
    }
    os.WriteFile("scene.riv", data, 0644)
}
```

## Builder API

### Shapes

```go
ab := b.Artboard("Demo", 400, 400)

// Solid-color rectangle
rect := ab.Rectangle(x, y, width, height).Fill(0xFFRRGGBB)

// Gradient ellipse
ellipse := ab.Ellipse(cx, cy, rx, ry).FillGradient(x1, y1, x2, y2,
    builder.GradientStop{Position: 0, Color: 0xFFFF0000},
    builder.GradientStop{Position: 1, Color: 0xFF0000FF},
)

// Stroke
ab.Rectangle(50, 50, 100, 100).Stroke(3.0, 0xFF000000)
```

### Animations

```go
anim := ab.Animation("move",
    builder.WithDuration(60),
    builder.WithFPS(60),
    builder.WithLoop(builder.LoopPingPong),
)

anim.KeyframeFloat(rect, builder.PropX,       0,  50.0, builder.CubicInterp{In: 0.25, Out: 0.75})
anim.KeyframeFloat(rect, builder.PropX,       60, 350.0, builder.CubicInterp{In: 0.25, Out: 0.75})
anim.KeyframeColor(rect, builder.PropColorValue, 0, 0xFFFF0000, builder.Linear())
```

Available prop constants: `PropX`, `PropY`, `PropRotation`, `PropScaleX`, `PropScaleY`, `PropOpacity`, `PropWidth`, `PropHeight`, `PropColorValue`.

Interpolation types: `Linear()`, `Hold()`, `CubicInterp{In, Out float64}`.

### State Machines

```go
sm := ab.StateMachine("controller")
onOff := sm.BoolInput("active")

layer := sm.Layer("main")
off := layer.AnimationState("off", offAnim)
on  := layer.AnimationState("on",  onAnim)

layer.Transition(off, on).BoolCondition(onOff, true)
layer.Transition(on, off).BoolCondition(onOff, false)
```

## CLI: rivtool

```bash
go install github.com/redriot-io/rive-go/cmd/rivtool@latest

# Inspect object tree
rivtool inspect scene.riv

# Validate fingerprint, version, and parent references
rivtool validate scene.riv

# Deep validation: also checks font glyph coverage for all text objects
rivtool verify --deep scene.riv
```
